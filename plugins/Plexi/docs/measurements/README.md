# v0.5 measurement manifest

Production JSFX Git blobs:

- v0.4 baseline: `15c49083f48e97e18a659604b7661591e038642d`
- v0.5 final: `21f0180aeb91cf2c8bd0e842b1d685cdd284ea4e`

All native runs used REAPER 7.47 Linux x86_64. No Windows listening test is
claimed. Synthetic inputs/IRs are generated by the scripts; no audio assets
or host binaries are bundled. Times depend on this shared execution environment.

| Record | Scope |
| --- | --- |
| [v0.4-baseline.json](v0.4-baseline.json) | Three native baseline renders; four levels, five coherent tones per rate; process CPU recorded |
| [v0.4-primitives.json](v0.4-primitives.json) | 225 memoryless original-equation diagnostics; not complete amplifier/circuit simulation |
| [v0.5-spectra.json](v0.5-spectra.json) | Nine production-source native renders, three rates and modes, same stimuli |
| [v0.5-native-stream.json](v0.5-native-stream.json) | 33 thirty-second native cases; memory/load/readiness and continuity diagnostics |
| [v0.5-latency.json](v0.5-latency.json) | Nine temporary identity-amplifier native cases; independent FIR/PDC comparison |
| [v0.5-invalid-input.json](v0.5-invalid-input.json) | Six ten-second native cases with invalid inputs and a latched pre-PCM finite-output guard |

The stream records predate addition of the explicit finite latch to the test
runner; that guard is verified in the separate invalid-input record. Both test
copies use the same final production DSP. `peak_64_sample_wall_seconds` includes
host scheduling/timer overhead and is not a hard real-time processing bound.
`child_process_cpu_seconds` is aggregate REAPER process user+system CPU time,
not device callback CPU. Values are null where the platform lacks `resource`.

Reproduction and method details are in [measurements](../plexi-v0.5-measurements.md)
and [testing](../plexi-v0.5-testing.md). Recorded-data regression tests do not
rerun a host or establish audible quality.
